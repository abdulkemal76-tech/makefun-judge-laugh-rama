Entry for the [Make the AI Judge Laugh](https://make.fun/bounty/u-rama-melon-make-the-ai-judge-laugh-302d0825)
bounty on [make.fun](https://make.fun): a program that writes one funny line
about office life, under 200 characters, to `/output/entry.txt`.

## The joke

> I filed ticket 4812 about my wobbly chair in March. IT closed it in October.
> The chair still wobbles, but now it wobbles with closure.

## Run

```sh
python3 -P -s main.py
cat /output/entry.txt
```

`main.py` uses only the Python standard library.
